# Demo Reset and Replay Procedure

Reset is available only to an authenticated Platform Administrator and only for the database-classified synthetic demo organization. The server rejects non-demo targets.

1. From Demo Center or the presentation controls, select Reset scenario.
2. Confirm the destructive-to-demo-state prompt.
3. Wait for the certified baseline confirmation.
4. Confirm three locations and the synthetic metric set.
5. Start the Monday Executive Briefing.

Replay performs reset followed by deterministic scenario start. Idempotent event keys and existence checks prevent duplicate recommendations, goals, and workflows. Never use reset against a customer organization.
