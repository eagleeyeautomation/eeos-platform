# EEOS Flagship Demo

This directory contains the version-controlled production package for the EEOS flagship demo. The live experience uses only the classified synthetic organization **Summit Home Services Group**. Large video masters belong in the approved media store, not Git.

## Opening sequence

Target: 16:9, 4K preferred, 1080p minimum, consistent cinematic frame rate, 30–45 seconds. Five modular clips transition from executive pressure to the live synthetic EEOS dashboard. Generated footage must contain no text or logos; accurate EEOS branding, titles, and real synthetic screenshots are added during editing.

## Safety

- No PRN Staffers records or identifiers.
- No production customer data, credentials, PHI, email addresses, or phone numbers.
- No generated software UI presented as real functionality.
- No clip is approved with watermarks, distorted people, malformed hands, unstable motion, or unreadable overlays.
