# Presenter rehearsal guide

Run and record six cycles: technical, presenter, five-minute, full executive, failure/fallback, and reset/replay. A cycle passes only when the presenter reaches Closing, sees no new material console error, makes no unsafe claim, and performs no external action.

Fallbacks:

- Autoplay blocked: select Play after a user gesture, or Skip Intro.
- Video unavailable or slow: use the poster/fallback and continue live.
- Copilot insufficient data: explain that refusal is a governance feature.
- Recent-auth expired: authenticate normally with password and MFA; never bypass or extend the window.
- Workflow already approved: do not replay the approval; reset the synthetic scenario with confirmation.
- Refresh or route reload: reopen the authorized presentation and confirm current known state.
- Fullscreen exit: continue in the browser or select fullscreen again.
- Connector warning: describe the truthful warning; do not claim external execution.

Keyboard: Right/Left navigate; Space controls the cinematic when focused on the opening; Escape exits fullscreen then presentation; N toggles notes; R requests confirmed restart; Q enters supported quick mode.
