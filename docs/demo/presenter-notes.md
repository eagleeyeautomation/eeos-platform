# Presenter Notes

The application contains step-specific notes with what to say, what to click, expected response, audience focus, fallback, and maximum time. Notes are hidden by default and require authenticated Platform Administrator access.

Keyboard controls: Right/Left advance and return, Escape exits, F requests fullscreen, and R restarts only after confirmation. Preserve normal focus behavior; keyboard shortcuts do not fire while typing in an input or text area.
